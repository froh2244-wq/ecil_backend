cli_ocr.py 사용 방법
====================

1. 개요
-------
cli_ocr.py는 PaddleOCR 3.7 일반 OCR 파이프라인으로 이미지에서 텍스트를 추출하는
터미널 전용 스크립트입니다. 인식 결과는 기본 표 또는 JSON 형식으로 출력할 수 있고,
추출한 텍스트만 UTF-8 텍스트 파일로 저장할 수도 있습니다.
검출 모델은 PP-OCRv6_medium_det, 인식 모델은 한국어·영어·숫자를 지원하는
korean_PP-OCRv5_mobile_rec을 사용합니다.

2. 실행 환경과 설치
-------------------
- Python 3.10 이상 (현재 확인된 환경: Windows 11 x64, Python 3.12.14)
- PaddleOCR 3.7.0, PaddleX 3.7.0, PaddlePaddle 3.2.0
- CPU 설치 기준이며, 버전은 requirements.txt에 고정되어 있습니다.

터미널에서 다음 명령을 실행합니다. PaddlePaddle CPU 패키지는 공식 CPU 인덱스에서
설치하도록 requirements.txt에 설정되어 있습니다.

    python -m pip install -r requirements.txt

PaddleOCR 모델 파일은 첫 실행 때 내려받습니다. 전처리에는 OpenCV(cv2)와
NumPy가 필요하며, `paddlex[ocr-core]` 설치에 포함됩니다. 누락 오류가 나면 다음
명령으로 보완할 수 있습니다.

    python -m pip install opencv-contrib-python numpy

GPU 설치는 CUDA·드라이버 및 장치에 따라 PaddlePaddle 패키지가 달라지므로, CPU용
requirements.txt를 그대로 사용하지 말고 PaddlePaddle 공식 설치 안내를 확인하세요.

3. 기본 실행
------------
스크립트가 있는 폴더에서 실행합니다.

    python cli_ocr.py -i 이미지파일경로

예시:

    python cli_ocr.py -i receipt.png

언어를 지정하려면 -l 또는 --lang 옵션을 사용합니다. 기본값은 korean이며, 모델은
영어와 숫자도 지원하므로 en도 허용됩니다.

    python cli_ocr.py --image sign.jpg --lang en
    python cli_ocr.py -i label.png -l korean

`ch` 등 이 모델이 지원하지 않는 언어를 지정하면 오류를 출력하고 종료합니다.
검출과 인식을 함께 수행하는 PaddleOCR 일반 OCR 파이프라인을 사용합니다.
추론 엔진은 `paddle_static`으로 지정합니다.

4. 옵션
-------
-i, --image PATH
    분석할 이미지 경로입니다. 필수 항목입니다.

-l, --lang LANG
    모델이 지원하는 언어입니다. korean 또는 en만 허용되며 기본값은 korean입니다.

--cls / --no-cls
    텍스트 줄 방향 분류 사용 여부입니다. PaddleOCR 3.x의
    use_textline_orientation 설정으로 연결됩니다. 기본값은 사용(--cls)입니다.
    끄려면 --no-cls를 지정합니다.

--preprocess / --no-preprocess
    OpenCV 이미지 전처리 사용 여부입니다. 기본값은 사용(--preprocess)입니다.
    작은 이미지는 최대 2배로 확대하고, 그레이스케일 및 CLAHE 대비 보정을
    적용합니다. 원본 이미지로 OCR하려면 --no-preprocess를 지정합니다.

--min-conf FLOAT
    출력에 포함할 최소 신뢰도입니다. 0.0부터 1.0 사이 값을 지정합니다.
    기본값은 0.0입니다. 지정한 값보다 낮은 결과는 출력 및 저장에서 제외됩니다.

-o, --output PATH
    인식한 텍스트를 UTF-8 텍스트 파일로 저장합니다. 저장 파일에는 인식된
    텍스트만 줄 단위로 기록됩니다. 파일 저장과 함께 결과도 표준 출력에
    표시됩니다.

--json
    기본 표 대신 JSON 배열을 표준 출력에 출력합니다. 각 결과에는 text,
    confidence, box 필드가 있습니다. box는 좌표 배열이며 좌표를 읽을 수
    없을 때는 null입니다.

PaddleOCR 3.x 결과 객체의 json["res"]에서 rec_texts, rec_scores,
rec_polys를 같은 인덱스끼리 묶어 기존 text, confidence, box 형식으로
변환합니다. 좌표는 다각형 rec_polys를 사용하며, 필드 길이가 맞지 않으면
잘못된 결과를 조용히 출력하지 않고 오류로 처리합니다.

-h, --help
    도움말을 표시합니다.

영양성분표 후보정
-----------------
인식 결과 문자열에 영양 항목명이 포함된 경우에만 다음 규칙을 적용합니다.

- 탄수화물, 당류, 지방, 단백질 등의 항목에서 숫자 뒤의 9를 g로 보정합니다.
  예: "단백질 209" -> "단백질 20g"
- 숫자 뒤 단위 ng를 mg로 보정합니다.
  예: "나트륨 200ng" -> "나트륨 200mg"

항목명과 수치가 서로 다른 OCR 결과 문자열로 분리되면 해당 수치에는 보정이
적용되지 않습니다. 영양성분표가 아닌 일반 문구는 보정하지 않습니다.

5. 실행 예시
------------
신뢰도 0.5 이상인 결과를 표로 출력:

    python cli_ocr.py -i receipt.png --min-conf 0.5

각도 분류기를 끄고 인식 텍스트를 파일로 저장:

    python cli_ocr.py -i receipt.png --no-cls -o receipt.txt

OpenCV 전처리를 끄고 원본 이미지로 실행:

    python cli_ocr.py -i receipt.png --no-preprocess

JSON 결과 출력:

    python cli_ocr.py -i receipt.png --json

JSON 결과를 파일로 리다이렉션:

    python cli_ocr.py -i receipt.png --json > result.json

JSON 출력에 안내 문구가 섞이지 않도록 모델 초기화 및 진행 안내는 표준
오류(stderr)로 출력됩니다. 위 리다이렉션은 표준 출력만 result.json에
저장합니다.

6. 출력 예시
------------
기본 표 출력 예시:

    No.  Confidence  Text
    ---  ----------  ----
      1      0.9821  영수증
      2      0.9145  합계 12,000원

JSON 출력 예시:

    [{"text": "영수증", "confidence": 0.9821, "box": [[12.0, 20.0], [95.0, 20.0], [95.0, 44.0], [12.0, 44.0]]}]

알레르기 키워드 판정
-------------------
테스트용 사용자 알레르기 성분은 복숭아와 오징어로 설정되어 있습니다.
OCR로 인식한 모든 텍스트에서 두 키워드를 찾아 판정하며, 공백이 끼어
인식된 `복 숭아`도 감지하도록 공백을 무시합니다. 판정 함수는
`detect_allergens(records)`이며 감지된 성분 목록을 반환합니다.

기본 표 출력 아래에 다음과 같은 알레르기 판정이 표시됩니다.

    ---------------------------------
    사용자 알레르기 성분: 복숭아, 오징어
    알레르기 감지: 알레르기 유발 원인 감지!
    감지된 알레르기 성분: 오징어
    ---------------------------------

해당 키워드가 없으면 `알레르기 감지: (알레르기 성분 감지 안됨)`으로 표시됩니다.
감지된 키워드가 여러 개면 `감지된 알레르기 성분`에 모두 표시됩니다.
`--json` 사용 시 표준 출력은 계속 JSON만 포함하며, 알레르기 판정 안내는
표준 오류(stderr)에 출력됩니다. 이 기능은 단순 키워드 기반 테스트 판정이며
의학적 알레르기 진단이 아닙니다.

7. 오류 처리
------------
- 이미지 경로가 없거나 파일이 아니면 오류를 표준 오류에 출력하고 종료 코드
  1로 종료합니다.
- PaddleOCR 실행 또는 출력 파일 저장에 실패한 경우에도 오류를 표준 오류에
  출력하고 종료 코드 1로 종료합니다.
- `PaddleOCR`에 `predict()`가 없다는 오류가 나오면 실행 중인 Python이 2.x 또는
  다른 경로의 `paddleocr`를 불러온 것입니다. CLI는 2.x `ocr()` API로 자동
  전환하지 않습니다. 다음 두 명령을 같은 터미널에서 실행해 설치를 확인하세요.

      python -c "import paddleocr; print(paddleocr.__version__, paddleocr.__file__)"
      python -m pip install -r requirements.txt

  특히 IDE나 가상환경에서 실행한다면 설치 명령과 `cli_ocr.py` 실행에 같은
  Python 실행 파일을 사용해야 합니다.
- 이미지에 인식할 텍스트가 없으면 기본 모드에서는 빈 표가, JSON 모드에서는
  빈 배열([])이 출력됩니다.
